SCUFFED PROMPT SETS
===================

Five thematic sets, matching the structure of the reference NHIE workbook:
1. Australian
2. VRChat
3. NSFW
4. Drinking
5. Gaming

TRUTH OR DARE
-------------
Each thematic file contains exactly 200 prompts:
- 100 {truth}
- 100 {dare}

Every Truth/Dare line begins with {truth} or {dare}.
Optional metadata tags are placed immediately after it:
[social] [relationship] [drinking] [nsfw]

Example:
{truth}[relationship] <player>, would you trust <rem_player> to plan a date for you?

Player placeholders are intentionally selective:
<player>      = player who triggered the prompt
<rem_player>  = another/remote player

SPIN THE WHEEL
--------------
Each thematic file contains exactly 200 wheel prompts.
These are deliberately written as group mechanics, votes, pair interactions,
temporary rules and quick challenges rather than disguised NHIE/Truth prompts.

Category tags are optional here too and, when present, appear first.

DESIGN SEPARATION
-----------------
NHIE: past experiences / "have you done this?"
Truth: opinions, preferences, hypothetical choices, current feelings
Dare: direct actions and performances
Wheel: room-wide targeting, voting, pair mechanics, temporary rules and chaos

Drinking prompts avoid mandatory heavy-consumption escalation; water,
non-alcoholic drinks, pacing and social challenges remain valid game actions.
NSFW prompts are adult-oriented but keep participation consent-based.
